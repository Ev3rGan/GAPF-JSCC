# 问题定义

## 1. 研究目标

本研究关注固定信道预算下、以来源图像为条件的感知忠实无线图像重建。

接收图像应在身份、物体数量、布局、空间关系、几何结构及其他由来源支持的属性上忠于发送图像。生成先验可以补全信道没有保留的细节，但不能自由替换已经成功传输的证据。

这比“生成语义上合理的图像”更严格。图像可以看起来真实，却对应错误实例、改变物体结构、移动内容或虚构来源不支持的细节。

## 2. 系统边界

记来源图像为 `x`。冻结的接收端 VAE 将其映射到接收生成器使用的原生 latent 坐标系：

\[
z = a\bigl(E_{\mathrm{VAE}}(x)-b\bigr).
\]

JSCC encoder 将该 latent 和公开信道状态映射为固定数量的复信道符号。经过信道后，接收端重建带噪 latent anchor `a_s`。

最终接收端组合三类信息：

- **已接收的来源证据**：带噪 GLINT anchor `a_s`；
- **公开信道状态**：SNR 或等价的信道质量变量；
- **接收端生成上下文与先验**：接收端可用、且未作为源相关 side information 发送的信息。

通信预算只统计实际发送的复信道符号。接收端生成上下文不计入源信息传输量，但必须单独披露。

## 3. 为什么需要两个阶段

Stage 1 与 Stage 2 回答的是不同问题。

### Stage 1：表示与传输

第一个问题不只是神经网络能否压缩图像，而是发送端能否传输一种表示，使其同时满足：

- 原生属于接收端生成器；
- 保留冻结 decoder 需要的空间与通道组织；
- 严格服从通信预算；
- 不依赖源相关旁路信息；
- 经过信道噪声后仍然有用。

GLINT 解决这一问题并输出 `a_s`，即接收端可观察的 anchor。

### Stage 2：证据约束的生成式重建

第二个问题不只是 diffusion/flow 模型能否利用条件，而是接收端能否借助强先验恢复缺失细节，同时不让先验覆盖可靠来源证据。

GAPF 在完整冻结 prior 轨迹中持续把 anchor 视为带噪证据，并限制最终学习动作的幅度。

## 4. 职责分解

| 职责 | 承担组件 |
|---|---|
| 表示并传输源特定信息 | GLINT encoder、信道和 decoder |
| 提供接收端可观察的忠实性参照 | GLINT anchor |
| 补充信道未支持的自然图像细节 | 冻结生成先验 |
| 在 prior 轨迹中注入空间证据 | TSET |
| 控制全局 anchor–prior 平衡 | SNR 条件化 posterior coupling |
| 修正 decoder 敏感的终点误差 | decoder-aligned multiscale direction |
| 防止无界终端覆盖 | source gate 与 trust-region projection |

这一职责分解是核心科学思想：区分“必须保留什么”和“允许重新生成什么”。

## 5. 优化视角

接收端可由下面的后验职责模型理解：

\[
p(z\mid a_s,s,p) \propto p_{\mathrm{prior}}(z\mid p)\,p_{\phi}(a_s\mid z,s).
\]

该分解是设计解释：冻结 prior 与接收证据承担不同职责。它不意味着非线性 GLINT 信道具有已知解析 likelihood，也不表示 GAPF 在进行精确贝叶斯后验采样。

## 6. 评测目标

目标是在匹配通信预算下改善 fidelity–perception trade-off。因此评测需要同时包含失真与感知指标、匹配的信道随机性和 seed、完整 cohort，以及重建型和生成型接收端的对比。

训练损失、小型诊断集、selector 子集和 train-holdout probe 可以解释机制，但不能建立最终系统性能。

## 7. 三种科学陈述层级

项目严格区分：

1. **数学保证**：例如终端动作存在显式上界；
2. **机制解释**：例如把缺失细节补全职责分配给 prior；
3. **经验结论**：例如在完整评测 cohort 上优于匹配基线。

第一类可以直接由公式推出；第二类需要谨慎的反事实证据；第三类必须依靠正式评测。正确理解 GLINT 与 GAPF 的前提，是不把这三个层级混为一谈。
