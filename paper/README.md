# 论文辅助材料

本目录公开论文写作和数学表达中具有长期复用价值的三份辅助材料。它们是 GAPF-JSCC 研究配套文档的一部分，不是投稿稿件、补充材料或完整复现包。

## 已公开文件

- [论文撰写现行规范](论文撰写现行规范.md)：跨模块写作规则、问题—方法—证据主线与压缩边界。
- [论文成稿验收标准](论文成稿验收标准.md)：从结构工作稿到最终投稿稿的检查门槛。
- [公式与符号审计表](公式与符号审计表.md)：V4 数学对象、公式职责、数据流、直接性质和证据边界。

## 未纳入公开仓库的工作文件

- V3/V4 TeX、PDF、图件、参考文献数据库和构建缓存；
- 不受页数约束的内容母稿；
- 逐轮模块访谈、修改日志与绘图决策记录；
- 本地同步元数据或机器特定路径。

这些工作文件继续保存在作者控制的本地论文工作区。公开仓库中的辅助材料不能替代论文正文的自洽说明，也不能独立支撑论文未报告的性能主张。

短论文与扩展文档的关系见[论文配套映射](../docs/paper-companion-map.md)。
