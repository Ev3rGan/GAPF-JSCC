# 论文子集规划

当前尚未把论文源文件复制进本仓库。

短论文与扩展仓库解释的关系见[论文配套映射](../docs/paper-companion-map.md)。

后续经作者再次批准后，本目录只应包含活跃论文工作集：

- 当前 V2 TeX 源文件；
- 该源文件实际引用的 figure；
- 论文所需且已核验的 BibTeX database；
- 受控本地 build script 与必要 class/style file；
- 列出未闭合字段的简短 manuscript-status 文件。

不应包含：

- 所有历史论文版本；
- build cache 或任意 PDF preview；
- 原始文献 PDF；
- 实验日志或 result directory；
- 无关研究笔记；
- 机器特定同步元数据。

## 尚待确定的权威模型

复制文件前，作者需要在两种模式中选择：

1. **权威论文模式**：本仓库成为论文源文件的权威位置；
2. **受控镜像模式**：权威论文仍在受控项目树中，只在审阅节点复制快照。

第一种便于协作编辑，但需要新的同步契约；第二种扰动较小，却增加 GitHub 副本过时的风险。当前仓库不替作者做此选择。
