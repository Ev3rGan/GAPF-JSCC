## 1. 写作目标与读者

- 论文面向语义通信领域科研读者：默认其熟悉 DeepJSCC 及主要重建型 JSCC 基线，具备一般深度学习基础，对生成式 JSCC 只有概括性了解，并且不预设其熟悉扩散模型、流模型、FLUX 或本文代码。
- 与重建型 JSCC 相关的通用基础只保留导出本文问题所必需的部分；当 GAPF 的理解依赖流模型特有的状态、方向、噪声水平或更新关系时，正文必须就地补充最低限度的生成模型基础，不能把这部分知识转嫁给读者。
- 正文必须让首次阅读者回答：问题如何定义与拆解，现有方法为何不足，GLINT 与 GAPF 分别改变什么对象、如何运行、为什么针对该问题，以及哪些结论来自数学构造、哪些仍需实验验证。
- 论文只呈现最终的 `Stage 1 GLINT → received latent anchor → Stage 2 GAPF` 主线。V1、DNLT、SACRA、nested GLINT 负结果和过程性方案不进入主论文。
- GitHub companion 可以提供完整推理、演进和实现解释，但不能替代主论文的基本自洽。

## 3. 论文唯一论证主线

全文从两个已确认事实出发：在带宽受限且存在信道噪声的传输条件下，重建型 JSCC 以失真恢复为主要目标，难以恢复充分的感知细节；现有生成式 JSCC 虽引入生成先验，却采用彼此不同的传输表示和生成接口。相关工作必须先分别说明这些路线的真实限制，再归纳共同缺口，不能把“生成结果可能偏离传输内容”写成所有生成式路线共有且已经充分论证的问题。

经作者确认，全文采用“一层总括、两个子缺口”的中心命题：现有生成式 JSCC 尚未同时解决传输表示与大型预训练生成器接收接口的协同设计。子缺口一是如何在带宽受限且带噪的信道上获得无需中间图像重建或额外表征转换、并与生成器原生空间兼容的接收表示；子缺口二是该表示经过有损压缩和信道后，如何以通信状态感知且参数高效的方式接入冻结流先验。两个子缺口分别导出 GLINT 与 GAPF，二者共同构成完整系统答案。

具体路线的代价可能表现为中间图像重建及再次编码造成的信息或表征转换损失、独立学习额外条件表示、依赖迭代后验推理，或联合训练专用生成解码器。正文只能把某项局限归于确实采用该路线的工作，不能将异质局限无差别合并；“尚未同时解决两个子缺口”的范围性判断仍须在相关工作重写时逐篇核验。

- Stage 1 回答“应当通过信道传输和恢复什么表示”：GLINT 面向带宽受限且带噪的链路恢复与接收端生成器空间兼容的 latent anchor。
- Stage 2 回答“如何让生成先验补细节而不摆脱信道约束”：GAPF 以锚点初始化生成状态，在先验提议中持续注入接收证据，限制可接受的锚点相对位移，并用信道状态协调该过程。终端细化与信赖域投影只作辅助端点约束，不承担 GAPF 的主要性能归因。
- 完整系统而不是两个孤立模块，是论文的顶层贡献和结果单位。
- 两阶段的贡献层级不完全对称：GAPF 是论文的核心方法创新；GLINT 是为 GAPF 建立合适接收表示而形成的必要通信方法。贡献表述不能把 GLINT 降为普通实现细节，也不能把二者写成创新性完全等价的两个并列模块。

“带宽受限”“有限信道资源”和“带噪信道”用于定义一般通信问题；具体 CBR 数值只属于系统约束与实验协议。CBR 取值不得被包装成方法设计或论文创新，只有在预算匹配和结果适用范围中才精确报告。

每个章节、段落、公式和实验都必须能回到这条主线；不能服务于问题、方法或证据的内容应删除或转入 companion。

## 4. 各模块的稳定职责

### Abstract

- 摘要长度控制在 75--100 词。
- 依次包含中心问题、完整系统、两个阶段的互补职责、完整系统评测范围和系统级核心结果。
- 问题背景使用“带宽受限且带噪的传输”，不使用“通信预算”作为一般场景概念，也不突出具体 CBR。
- 摘要的问题句重点落在受信道损伤的接收表示如何有效接入冻结预训练生成器；generator-native 表示作为 GLINT 对该接口问题的具体解法，在方法句中引入，而不必包装成同等层级的原初研究缺口。
- 先提出完整 GAPF-JSCC，再用一个职责从句说明 GLINT、一个职责从句说明 GAPF；不出现 calibration、lifting、TSET、coupling、trust region 等内部机制。
- 方法层面使用 pretrained flow-based generator，并在实验或实现范围中说明当前系统由冻结 FLUX 实例化，避免泛化到未验证生成器。
- 首次描述 GLINT 的传输对象时写成“the VAE latent used by the pretrained receiver-side generator”或同义关系从句；定义后使用 received VAE latent 或 latent anchor。`generator-native` 可以保留在 GLINT 方法名称中，但不作为反复出现的抽象对象名，也不用含义更宽泛的 feature representation 替代。
- 摘要对相关工作缺口采用审慎强度：说明受压缩和信道噪声影响的接收表示如何有效接入冻结预训练生成器仍未得到充分研究，不写成所有现有方法均“失败”。
- 不按 Stage 1/Stage 2 分开汇报结果，不写精确 CBR、SNR、指标数值或分条件比较。摘要结尾只保留一句完整系统级定性结果：概括稳定的感知质量优势，同时明确其伴随的像素保真度 trade-off；不把实验网格、阶段诊断或单项最优写入摘要。

### Introduction and related work

- 从 DeepJSCC 作为科研起点引入端到端 JSCC，用三至四句集合式说明后续重建型方法改善表示、码率与信道适应能力，但其失真导向的重建范式在带宽受限条件下仍难以恢复充分的感知细节。不得逐项展开 NTSCC、SwinJSCC 或 MambaJSCC 中与本文缺口无关的机制。
- 从其他重建型 JSCC 的边界自然过渡到生成式语义通信；通过重建型与生成型方法的比较归纳当前缺口。
- 生成式 JSCC 相关工作的组织以内部 V1 论文快照中已经反复优化的路线区分和因果顺序为叙事基线，再用当前 companion 中已核验的工作补充或修正；只继承叙事逻辑和仍成立的事实，不带回 DNLT、SACRA 或旧贡献表述。
- 生成式 JSCC 按接收接口而不是按论文逐篇组织：中间图像重建、信道观测后验指导、独立学习的 feature/latent condition、联合训练专用生成接收机。每条路线只写与本文接口问题直接相关的方法事实和特有限制，再归纳共同缺口。
- 相关工作不是综述本身，而是为“问题为何存在、可借鉴什么、现有工作缺什么”服务。
- 跨领域思想来源保留为与通信相关工作同等重要的紧凑桥接段：VAE latent generative models 解释为何选择接收生成器使用的 latent space；冻结生成器控制和图像恢复工作解释轻量空间证据接口的来源；随后指出干净控制或既定退化不能直接代表受有损压缩、信道噪声和信道状态影响的接收表示。该桥接是方法合理性论证，不得作为一般背景优先删除；具体论文谱系留在 companion。
- 引言只用一句定位当前实例为工作于 VAE latent space 的冻结 rectified-flow generator，不在引言展开 flow 数学；目标读者所需的 state、direction、noise level 与 update 基础在 GAPF 首次使用前由方法部分承担。
- 最后引出完整 GAPF-JSCC 与可由后文兑现的贡献。贡献固定为四个条目：完整系统与问题；GLINT 的派生输入接口职责；GAPF 的核心创新；完整系统实验验证。第四条可以比摘要给出更完整的定性结果，但仍不枚举精确 CBR/SNR 网格。不得把 GLINT 与 GAPF 写成创新性完全对称，也不得再把第四项并入前三项。

### System model and problem formulation

- 按“通信对象与资源 → 完整端到端前向路线 → 两阶段职责与系统级目标”组织。完整路线由 Figure 1 建立总体认知，正文用简洁段落解释图中的模块、数学符号流和阶段连接，不把内部工作骨架原样写成一串教学式箭头。
- 明确源图像、接收端预训练生成器使用的 VAE latent、信道符号、AWGN、CBR、接收端运行时已知信息、本地冻结资源和两阶段训练对象。具体 CBR 取值只进入实验协议。
- 接收端资源分为：实际跨信道的复符号；运行时已知的接收符号与 SNR；本地冻结 VAE、flow prior/scheduler 和本地随机噪声。未改变、未比较且未参与论证的固定 prompt/context 不进入系统接口。
- 在模块细节之前给出 Stage 1 与 Stage 2 的职责边界、输入输出和完整前向路线。System Model 的主路径只把 GLINT anchor 作为 GAPF 输入；直接 VAE 解码在 GLINT 训练目标和实验诊断处定义，不写成系统的第二个并列输出。
- 系统级目标用文字界定为带宽受限、带噪条件下的 fidelity--perception balance。真实的 GLINT/GAPF 训练损失留在各方法小节；主论文不加入仅作思想解释的 posterior factorization，也不制造未被实际联合优化的统一加权目标。
- 不显式暴露没有被改变、比较、消融或用于论证的生成器内部固定条件。

### Method

- 每个小节以局部失败模式和设计要求开始，而不是从组件名或公式直接开始。
- 每组保留公式依次完成：局部问题 → 核心关系 → 全符号定义 → 使用原符号的直接计算说明 → 直接性质 → 输出去向。
- 方法公式负责说明“如何运行”和“为什么针对当前问题”；是否提升性能由实验负责。
- Stage 1 与 Stage 2 使用同一验收尺度，不能只修最近被指出的一侧。
- GLINT 的问题链和顺序固定为三个连续 mismatch：第一，不同 VAE latent 通道的数值尺度不均；第二，latent 的局部空间可预测性尚未被组织成适合带宽受限链路的表示；第三，相近的 latent 数值误差经过冻结 VAE decoder 后可能产生不同的视觉影响。三者依次导出固定逐通道 calibration、可逆且逐通道执行的 separable lifting 与有损 JSCC bottleneck、decoder-aligned objective，并最终产生供 GAPF 使用的接收 latent anchor。不得用另一组抽象问题替换这三项，也不得打乱其因果顺序。
- GLINT 的 lifting 至少保留一组经实现核验的 predict--update 关系：先说明 $2\times2$ polyphase 分量如何产生三个 prediction residual，再说明这些 residual 如何更新 coarse field，最后说明 coarse/detail 组合为何为后续有损通信提供局部空间组织以及逆变换如何返回 latent。网络内部结构可以封装为算子，但上述结构含义不能只由算子名或“可逆”二字代替。
- GLINT 的有损路径必须是一组连续且可追踪的关系，从校准 latent、lifting-domain 表示、固定信道使用数的发送符号和接收符号，一直闭合到接收 latent anchor；每个中间对象的记号应体现其常规数学或通信职责，不能只沿用历史实现变量名。
- GLINT 训练目标保留两类职责：decoder-visible discrepancy 与 latent consistency；具体像素、LPIPS 和冻结 decoder feature discrepancy 可封装在前者中，不将每个内部损失项提升为独立方法贡献。
- GLINT calibration 保留可逆算子定义，并说明它使用训练集固定的逐通道统计量；逐通道 z-score 算术不必在主论文展开。
- GAPF 必须采用最小 frozen-flow baseline--delta 结构。先用一小段或一组紧凑公式定义冻结 prior/scheduler 一步所需的 flow state、time/noise level、predicted direction、clean-latent proposal 和 unchanged update；随后展开三项核心 trajectory 改动：anchor--noise initialization、TSET-conditioned proposal 与 anchor-relative acceptance，再说明信道状态如何协调接受强度。终端细化与信赖域投影以紧凑的辅助端点路径呈现，不与三项核心 trajectory 机制并列。
- frozen-flow baseline 的批准骨架至少包含 $\mathbf v_k^0=\mathcal F_{\Theta_{\rm prior}}(\mathbf u_k,t_k)$、$\mathbf z_k^0=\Pi^{-1}(\mathbf u_k-\sigma_k\mathbf v_k^0)$ 以及冻结 scheduler 如何利用该 proposal 得到下一状态。这里 $\mathbf u_k$ 是第 $k$ 步 packed flow state，$\mathbf v_k^0$ 是未条件化冻结先验给出的 velocity，$\mathbf z_k^0$ 是相应 clean-latent estimate；“冻结 velocity → clean-latent estimate → unchanged scheduler update”这一关系不得删改。正文须以最低限度解释 velocity、clean-latent estimate 和 scheduler update 的关系，不展开 flow-matching 训练目标、连续时间 ODE 或 FLUX block 内部。
- GAPF 的核心问题链和顺序固定为：纯噪声起点没有把接收 latent 放入生成状态 → anchor--noise initialization；仅在起点使用 anchor 不能使冻结 prior 在形成中间结构时持续获得接收空间证据 → TSET-conditioned proposal；条件化能够改变 proposal，却不能限制 prior proposal 相对 anchor 的位移 → anchor-relative acceptance。信道状态调节接受强度，并同时为辅助端点校正提供强度控制。轨迹结束后的终端细化与信赖域投影是辅助机制，不再作为第四项同级核心机制或主要性能来源。
- GAPF 中 `posterior` 的操作性含义固定为：冻结生成 prior 在接收 latent anchor $\widehat{\mathbf z}$ 和信道状态 $\gamma$ 条件下形成的学习式近似恢复过程。evidence--prior 结合由实际前向机制实现，不使用缺乏解析 likelihood 的 posterior factorization 作为正文数学起点。
- TSET 公式与 baseline 逐项对照：它以当前 flow state、packed $\widehat{\mathbf z}$、$\gamma$ 和当前噪声水平产生空间 residual；该 residual 注入冻结 prior 的 image tokens 后得到 anchor-conditioned velocity，并由与 baseline 相同的 clean-latent 关系形成 proposal。正文不展开 TSET 内部投影、局部混合或具体 block 结构。
- anchor-relative acceptance 保留相对位移等式、unchanged scheduler update、线段关系与位移范数收缩性质。$\beta(\gamma)$ 解释为接受的 prior displacement 比例；不能退化为没有参照对象的普通插值描述。
- 辅助 terminal path 只保留理解构造约束所需的最小闭环：冻结流终点 $\mathbf z^{\rm flow}$、anchor--endpoint residual $\boldsymbol\Delta$、由接收端复合算子 $\mathcal R_{\phi_R}$ 形成的校正、$\alpha(\gamma)$ 强度控制、trust-set projection、最终 $\mathbf z^\star$ 与直接幅度上界。固定 local gate、RMS 尺度匹配及投影的内部代数封装在复合算子中，不再作为正文独立步骤或符号链展开。
- $\beta(\gamma)$ 与 $\alpha(\gamma)$ 在各自作用位置首次解释，并用一条联合约束给出范围和单调方向：高 SNR 时 $\beta(\gamma)$ 接受更少 prior displacement，$\alpha(\gamma)$ 调节辅助端点校正的强度。信道状态协调属于 GAPF 核心设计，但辅助终端路径不因此成为独立贡献。
- GAPF 训练目标在完整推理链之后采用两职责形式 $\mathcal L_{\rm GAPF}=\mathcal L_{\rm img}(\widehat{\mathbf x},\mathbf x)+\mu_z\operatorname{NMSE}(\mathbf z^\star,\mathbf z)$；$\mathcal L_{\rm img}$ 封装 LPIPS 与图像域 $\ell_1$，$\mu_z$ 与 GLINT 的 $\lambda_z$ 分离以避免跨阶段权重混淆。同处明确只训练 TSET、辅助 terminal correction 算子的学习参数和 controllers，GLINT、VAE、flow prior 与 scheduler 冻结；TBPTT-1 和具体更新数属于训练/实验协议。
- 上述 baseline 只服务于区分原有流模型运算与本文创新，不扩展为 rectified-flow 教程；不得为了压缩篇幅删除 baseline，也不得把基础定义重新散入各 GAPF 机制而模糊创新边界。

### Experiments

- 当前 Letter 的实验大章节只保留 `Experimental Setup` 和 `Experimental Results` 两个二级模块；GLINT 诊断、定量比较和定性比较均归入 `Experimental Results`。不设 `Ablation Study`、不保留消融表或 TBD。
- `Experimental Setup` 按“数据集与数据处理 → 指标及职责 → 比较方法与公平性 → 训练和推理实现”组织为四个紧凑段落。优化器和 learning rate 是必要实现信息；完整优化器日程、batch 细节和训练策略可因篇幅省略。当前已由权威配置与正式训练 manifest 核验：GLINT 使用 AdamW，峰值学习率为 $5\times10^{-4}$；GAPF 使用 AdamW，TSET 与 terminal correction operator 的学习率为 $10^{-4}$，SNR controllers 的学习率为 $10^{-3}$。必须明确顺序训练边界：先训练 GLINT；训练 GAPF 时冻结 GLINT、VAE、flow prior 与 scheduler，并只报告 Stage II 实际可训练对象及其参数量。若训练版本变化，须重新从对应权威配置或 manifest 核验，不能沿用历史数值。

## 5. 公式与符号铁律

以下规则不因篇幅、措辞优化或抽象层级变化而放宽：

已批准的系统主路径符号为：源图像 $\mathbf x$，冻结 VAE latent $\mathbf z$，发送复符号 $\mathbf s$，接收符号 $\mathbf y=\mathbf s+\mathbf n$，信道噪声 $\mathbf n$，SNR $\gamma$，GLINT 恢复并供 GAPF 使用的 latent anchor $\widehat{\mathbf z}$，GAPF 最终 latent $\mathbf z^\star$，最终重建 $\widehat{\mathbf x}$。anchor 是 $\widehat{\mathbf z}$ 的方法职责，不再另设 $\mathbf a_s$。

已批准的 GLINT 内部符号为：校准 latent $\bar{\mathbf z}=\mathcal C(\mathbf z)$；四个 $2\times2$ polyphase 分量 $\bar{\mathbf z}^{(0)},\ldots,\bar{\mathbf z}^{(3)}$；prediction residual $\mathbf d_i$；更新后的 coarse field $\boldsymbol\ell$；lifting-domain latent $\mathbf z_{\rm L}=[\boldsymbol\ell,\mathbf d_1,\mathbf d_2,\mathbf d_3]$ 及其接收估计 $\widehat{\mathbf z}_{\rm L}$。下标 $\rm L$ 首次出现时必须定义为 lifting domain。predict--update 的精确依赖必须依据真实实现核验，不得由记号反推。

已批准的 GAPF 内部符号为：第 $k$ 步 packed flow state $\mathbf u_k$；未条件化冻结先验 velocity $\mathbf v_k^0$ 及其 clean-latent estimate $\mathbf z_k^0$；TSET spatial evidence residual $\mathbf e_k$；anchor-conditioned velocity $\mathbf v_k^{\rm cond}$；prior proposal $\mathbf z_k^{\rm prop}$；anchor-relative accepted latent $\mathbf z_k^{\rm acc}$；冻结流终点 $\mathbf z^{\rm flow}=\Pi^{-1}(\mathbf u_K)$；anchor--endpoint residual $\boldsymbol\Delta=\widehat{\mathbf z}-\mathbf z^{\rm flow}$；由复合终端算子提供候选并经 trust projection 得到的辅助 correction $\boldsymbol\delta$。最终 latent 固定为 $\mathbf z^\star=\mathbf z^{\rm flow}+\boldsymbol\delta$。$\boldsymbol\delta_{\rm raw}$、$\mathbf m$ 与 $\widetilde{\boldsymbol\delta}$ 不再是 Letter 正文符号，只属于被复合算子封装的实现内部。

已批准的 GAPF 算子为：$\Pi/\Pi^{-1}$ 表示 frozen pack/unpack；$\mathcal F_{\Theta_{\rm prior}}$ 表示 frozen flow prior；$\mathcal T_{\phi_T}$ 表示可训练 TSET；$\mathcal U_{\rm flow}$ 表示 unchanged frozen scheduler update；$\mathcal R_{\phi_R}$ 表示辅助 terminal correction 的复合接收端算子，学习参数为 $\phi_R$，固定 gate 与尺度匹配封装在其内；$\mathcal B_\kappa(\boldsymbol\Delta)$ 表示以零为中心、RMS 半径为 $\kappa\RMS(\boldsymbol\Delta)$ 的 trust set。语义上标 `cond`、`prop` 与 `acc` 分别只表示 conditioned、proposal 与 accepted，不得换回容易混淆的 `pri`、`anc`。
